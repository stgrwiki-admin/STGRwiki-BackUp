*&font(#3BB240){基}本情報
***&underdot(#3BB240,3px){&icon_fa(fa-solid fa-circle-info)&nbsp(2)概要　}
&font(){ARCANA}所属の[[麻林>麻林　ラル]]が代表を務める興行会社。
-一定周期でイベントを開催。血や銃声の飛び交う何でもありな体験を提供する。
-黒市民間での関係値作りや、ブラックビジネスの宣伝なども行えるよう、社交の場としても動く予定。
-地域貢献システムを活用できないか検討中。
//
***&underdot(#3BB240,3px){&icon_fa(fa-solid fa-circle-info)&nbsp(2)由来　}
&u(){&ruby(マイナー){小}アルカナのWands(杖)の5から。}
#size(30%){　}
#openclose(show=＞ Wandsの意味){
▪&nbsp()火を起こすために使うこん棒であるワンドは「何か」を起こす、始めることを表す。
▪&nbsp()また、麻林は武器としての側面でも捉えている。}
#openclose(show=＞ 5の意味){
▪&nbsp()数字の5は、自由や変化を表す数字であり、5人の男が乱闘している絵柄から、熱心な競争もとい、理想が変化・発展していくことを意味する。}
-下部組織らしく、ARCANA命名由来のタロットカードにちなんでいる。
-会社コンセプトから連想&openclose2(show=※){「争いや新しい物を生み出す → 遊び → おもちゃ箱 → ToyBox」}したポップな印象を持つ「ToyBox」という単語が命名のベース。
-5の意味を含ませる目的で、Boxの"B"を似た音である"V"に置き換え、さらに似た形である5のギリシャ文字"Ⅴ"で表記。遊び心をくすぐる会社名となった。

*&font(#3BB240){活}動情報
***&underdot(#3BB240,3px){&icon_fa(fa-solid fa-circle-info)&nbsp(2)概要　}
主に、[[無馬グループ]]では行えない、黒市民向けのイベントや、背後に黒市民が関わるためのイベントを企画・運営する。

**興行事業
****&underdot(#3BB240,3px){1. ブレイキング・タウン} &small(){(予定)}
拳のみの地下格闘技大会。
-FIBの地下にある格闘場を使った格闘技大会。
-[[過去主催者>いわさき　そす]]より権利買収済。
//
****&underdot(#3BB240,3px){2. 闇オークション} &small(){(予定)}
表向きに出来ない商品を扱う黒市民向けオークション。&font(11,#aaa){某漫画のヨークシンイメージ。}
現在入金するためのシステム構想を考案中。
-取り扱い商品は、ブースティング車両等の盗難車をメインに、物品から情報まで制限なし。
//
**サービス
****&underdot(#3BB240,3px){1. 白市民向けイベントの企画及び運営補佐}
主にイベントのノウハウがない顧客向けに、地域貢券の確保を目的としたイベントの開催をサポートする。
-顧客側の要請に応じて、複数段階に区分けされたプランを提供予定。
-予定されているプラン（一部）&br()「イベント企画書のみの提供」&br()「イベント企画書の提供及び当日スタッフとしての人員提供等の部分的運営補佐」&br()「イベント企画書の提供及びイベント会場・必要資材・人員等の提供等の全面的運営補佐」
