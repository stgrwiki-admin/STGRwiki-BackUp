***&underdot(#9966CC,3px){&icon_fa(fa-solid fa-circle-info)&space(2)概要　}
[[カジノオーナー>無馬　かな]]にバーの全権を任された[[鳥羽 咲夜>鳥羽　咲夜]]がマスターを務めるバー。
-[[カジノ]]が提供するサービスの1つとして、カジノの改装グランドオープンにて一階へ併設。
-「白市民でも手が届いて楽しめる」をテーマとしたメニュー、サービスを展開中。
//
***&underdot(#9966CC,3px){&icon_fa(fa-solid fa-circle-info)&space(2)由来　}
「謙虚」「謙譲」&bold(){「強運」}の花言葉がある「アベリア」から。[[&icon_fa(fa-brands fa-twitter)>https://twitter.com/sakuyatobari/status/1742008989926519033]]
&openclose2(show=＞ロゴ){&br()&blankimg(https://pbs.twimg.com/media/GYetJrVaUAAnicv?format=jpg,x=240,y=180)&br()}
//
***&underdot(#9966CC,3px){&icon_fa(fa-solid fa-bell-concierge)&space(2)サービス　}
-従業員をイメージしたカクテルをメインに販売。
-[[鳥羽>鳥羽　咲夜]]によるオリジナルカクテルの開発、販売サービスが受けられる。
-市内の各飲食店と提携し、倍額で仕入れたフード商品をカクテル購入者に無償で提供。新商品等の宣伝も担っている。
-ラッキーホイールのドリンク当たりで入手できる、カジノバーガー、カジノコーラは「カクテル交換権」として使える。
//-オリジナルカクテルの宣伝をイベント会社「[[GoodbyeCompany>GoodbyeCircus]]（グッバイカンパニー）」に依頼予定。

***&underdot(#9966CC,3px){&icon_fa(fa-solid fa-info-circle)&space(2)業務内容　}
-[[カジノ]]内店舗の為、飲食の販売だけでなくカジノの業務内容にも従う。
--バー業務だけでなく、カジノルールも答えられるようにする必要がある。
//
***&underdot(#9966CC,3px){&icon_fa(fa-solid fa-info-circle)&space(2)雇用情報　}
-基本的に[[カジノ]]業務の延長である為、カジノの雇用規定に従う。
-カジノ従業員内に BAR業務を専門で行う「BARスタッフ」という枠組みがあったが、現在は廃止、統合された。
--これに伴い、BARスタッフ関係なくカジノ従業員全員が BAR業務を担当する。
-&openclose2(show=当時のBARスタッフ){&nbsp(br,2)[[鳥羽　咲夜]]、[[イナ　イロハ]]、[[龍造寺　ケンシロウ]]}

//
***&underdot(#9966CC,3px){&icon_fa(fa-solid fa-sack-dollar)&space(2)給与形態　}
-[[カジノ]]内店舗の為、基本的な給料制度はカジノに準ずるが、BAR独自の給与制度を取っている。
-給与は、飲食の売上から支払われる。
--内訳は、オリジナルカクテルは売った人に全額、従業員カクテルは売った人とモチーフとなった従業員へ半額ずつ。

鳥羽によるオリジナルカクテルの開発と制作、バーで1ヶ月販売される権利を購入できるサービス。
-実際に夢の世界でも制作できるレシピが公表される。

-月5枠まで。（鳥羽のスケジュール次第）
-特別な物は割増料金で枠外の追加対応を行っていたが、2024年からは枠内のみとなっている。
***&underdot(#9966CC,3px){◆&space(1)価格　}
-基本5000万円。
-「白市民パス」利用者は半額サービス有。団体宛のものは白黒関係なく5000万で依頼できる。
-繁忙期シーズンの受注は場合により値上がる可能性がある（最大2倍）[[価格詳細&icon_fa(fa-brands fa-twitter)>>https://twitter.com/sakuyatobari/status/1736459810802119023]]
-5000万円はカクテルレシピの制作料であり、個々のカクテル代は都度料金となっている。
***&underdot(#9966CC,3px){◆&space(1)取り扱い　}
-基本的な販売期間は提供から１ヶ月間。
-期間中は店頭に並ぶため誰でも購入することができる。
-１ヶ月経過後は、関連者のみ「いつもの」と注文することで購入が可能。
-その他、依頼者の意向やその時々のストーリーを重視した対応を取っている。
