**シャンクズプロモーションとは？
&font(b,#FFFFFF,#000000){　会社情報　}
・&bold(){[[四皇　シャンクズ]]が社長を務める、ロスサントス初のジョブ付き芸能プロダクション 兼 イベント会社。}&br()通称[[シャンプロ>シャンクズプロモーション]]もしくは[[クズプロ>シャンクズプロモーション]]。
・[[所属アーティスト>シャンクズプロモーション/ARTIST]]のマネジメントや音楽ライブ等の、エンターテインメント事業を展開している。
&font(b,#FFFFFF,#000000){　業種紹介　}
・&u(){芸能プロダクション}として、[[FATS＆SUGAR>シャンクズプロモーション/ARTIST#FATS＆SUGAR]]などの多彩な才能を発揮する[[アーティスト>シャンクズプロモーション/ARTIST]]が多数所属している。
・・[[各アーティスト>シャンクズプロモーション/ARTIST]]のマネジメント・プロデュース業務を行っている。
・&u(){イベント会社}として、街の住民を巻き込んだ[[音楽イベント>シャンクズプロモーション/LIVE／EVENT]]などを開催している。
・・定期的に[[イベント>シャンクズプロモーション/LIVE／EVENT]]を開催し、街の活性化につなげている。
・[[イベント>シャンクズプロモーション/LIVE／EVENT]]時には、アーティストグッズを作成して販売している。
&font(b,#FFFFFF,#000000){　事業内容　}
・主に下記の事業を展開している。
・・単独イベント：[[所属アーティスト>シャンクズプロモーション/ARTIST]]の音楽ライブや、バラエティイベントの開催。
・・外部イベント出演：依頼があれば[[所属アーティスト>シャンクズプロモーション/ARTIST]]が、他主催の[[イベント>シャンクズプロモーション/LIVE／EVENT]]へ出演。
#region(Season1)閉じる
・単独イベント：[[所属アーティスト>シャンクズプロモーション/ARTIST]]の音楽ライブや、バラエティイベントの開催。
・定期開催イベント：[[丘猫>丘猫　まる]]が主任となり[[GBC>GoodbyeCircus#Goodbye Company]]と共同で展開していた「[[ひみつの音楽会>シャンクズプロモーション/LIVE／EVENT#ひみつの音楽会]]」事業。
・外部イベント出演：依頼があれば[[所属アーティスト>シャンクズプロモーション/ARTIST]]が、他主催の[[イベント>シャンクズプロモーション/LIVE／EVENT]]へ出演。
・飲食事業：[[For Emperors]]を運営していて、飲食店として商品を提供。
・ボイス事業：[[シャンクズオンデマンド（SOD）>シャンクズプロモーション/BUSINESS#シャンクズオンデマンド]]を運営していて、癒やしを届ける音声作品を販売。
#endregion

&font(b,#FFFFFF,#000000){　特徴　}
・[[所属アーティスト>シャンクズプロモーション/ARTIST]]・[[社員>シャンクズプロモーション/STAFF]]のスキルや知名度、「[[NO LIMIT]]」メンバーも含めた豊富な経験知識から、一つ一つの興行スケールや完成度が高い。
・・その為、演者だけでなく事務所全体を応援してくれてる市民も多くい。
・主任として企画/運営ができる[[社員>シャンクズプロモーション/STAFF]]が多く、演者だけでなく[[スタッフ>シャンクズプロモーション/STAFF]]の人材も豊富に揃っている。
・[[イベント>シャンクズプロモーション/LIVE／EVENT]]前には街中にイベントポスターを掲示して、[[イベント>シャンクズプロモーション/LIVE／EVENT]]の周知や盛り上がりを演出するなど準備を怠らない。
・大人数が集まる[[イベント>シャンクズプロモーション/LIVE／EVENT]]は、街の歪み対策の為に[[出演者スタッフ>シャンクズプロモーション/STAFF]]を含めて50人程度に収まるようにしている。
&font(b,#FFFFFF,#000000){　各芸能業界との関係　}
・共に街を盛り上げたいという思いから、ロスサントスの各芸能業界会社とも良好な関係を築いている。
#region(Season1)閉じる
・同業である芸能事務所「[[Goodbye Company>GoodbyeCircus#Goodbye Company]]」とのパイプもあり、[[GBC>GoodbyeCircus]]主催のイベントへ招待されるなど友好的な関係を築いている。
・・[[Goodbye Company>GoodbyeCircus#Goodbye Company]]共同開催で「[[クリスマス野外ライブ>シャンクズプロモーション/LIVE／EVENT#突発クリスマスライブ]]」や「[[ひみつの音楽会>シャンクズプロモーション/LIVE／EVENT#ひみつの音楽会]]」などの開催をした。
・ステージがある飲食店「[[ShanaoR]]」と良好な関係を築いており、[[所属アーティスト>シャンクズプロモーション/ARTIST#葵井　優]]の[[ライブイベント>シャンクズプロモーション/LIVE／EVENT#AoiYuu1stsoloLive]]の開催をしている。
・[[麻林　ラル]]のレコード店「[[麻SICK RECORDS]]」からは業務提携を持ち掛けられた。[[シャンプロ>シャンクズプロモーション]]から所属タレントの楽曲を提供し、レコードの売り上げの一部を受け取るという構想であったが具体的な話は進まなかった。現在ではレコード事業の内容が自社でも出来る事などを理由に、社長の[[シャンクズ>[四皇　シャンクズ]]は難色を示している。
#endregion

**ギャング「[[NO LIMIT]]」との関係
・「[[シャンクズプロモーション]]」は、ギャング「[[NO LIMIT]]」のフロント企業として正式に開業した。
・・しかし[[ギャング]]側の活動理念として、芸能･エンタメ業をする上で白市民との間に亀裂が生じるのは致命的な為、「市民との不要な争いは避ける」こととしている。
・・その為、[[ギャング]]である｢[[NO LIMIT]]｣と白市民交流のある「[[シャンクズプロモーション]]」は切り離して考えられている。
・基本的に「&bold(){シャンクズプロモーションの所属タレントと[[社員>シャンクズプロモーション/STAFF]]は、ギャング[[NO LIMIT]]とは全くの無関係な立場}」という方針がある。
・・事務所には[[ギャング]]と本当に無関係な[[白市民タレント>シャンクズプロモーション/ARTIST]]や[[社員>シャンクズプロモーション/STAFF]]が、会社は[[ギャング]][[NO LIMIT]]と関係していると理解したうえで所属している。
・・また、社長の[[四皇　シャンクズ]]以外の[[NO LIMIT]]メンバーがタレントや[[社員>シャンクズプロモーション/STAFF]]として関わる時は、芸名や偽名を用いた変装をして携わっている。
・・上記以外にも[[ギャング]]と無関係な白市民が、諸事情により変装をして別人として所属しているという特例もある。
・しかし、市民には変装してもバレている人がいたり、[[NO LIMIT]]と[[シャンプロ>シャンクズプロモーション]]の関係性を知ってる人も多い事。そして[[シャンクズプロモーション]]の実績から市民の信頼を得ている事から、現在そこまで完全に分けている訳ではない。
