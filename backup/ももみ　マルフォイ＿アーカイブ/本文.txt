//リンク編集のワンテクニック
//youtubeおよびtwichのリンクを添付する際に、サイトからコピペで添付すると下記のような形になるが...
//https://www.youtube.com/watch?v=q-McT7amS-E&pp=0gcJCY0JAYcqIYzv
//https://www.twitch.tv/videos/2468109434?filter=archives&sort=time
//
//これらは一部を書き換えor削除により、文字数を抑えることができる。具体的には、下記の「」で囲った部分(www部や、&,?から続く後半の部分)を削除しても問題なくリンクとして動作する。
//https://www.youtube.com/watch?v=q-McT7amS-E　「 &pp=0gcJCY0JAYcqIYzv 」
//https://　「　www.　」　twitch.tv/videos/2468109434　「　?filter=archives&sort=time　」
//
//加えて、youtubeのみさらに書き換えで短いリンクにすることができ、具体的には下記の「」で囲ったhttps//の後から?v=の部分を「youtu.be/」に書き換えられる。
//https://　「　www.youtube.com/watch?v=　」　q-McT7amS-E
//
//これらをすると最終的に(youtubeのみ)下記のようになる。（但し、時間指定リンクの場合、/liveになっており、この部分を書き換えると時間指定が機能しなくなるので注意）
//https://www.youtube.com/watch?v=q-McT7amS-E&pp=0gcJCY0JAYcqIYzv
//　　　↓
//https://youtu.be/q-McT7amS-E
//これらを多用することで、結構な文字数を削減できるのでぜひ活用してみてください。
