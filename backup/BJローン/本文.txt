***&underdot(#00552e,3px){1) 会議内容}
&bold(){「BJローンは今、お金を貸す“ローン業”ができない。だから“新しい稼ぎ方”として、街の電子決済（デビット）事業を始める」}
&font(20px,#fcc800){▪&space()}新事業の中身
&font(20px,#fcc800){▪&space()}運用方法（人力・手間・役割分担）
&font(20px,#fcc800){▪&space()}会社のスタイル（完璧より“回しながら改善”）
&font(20px,#fcc800){▪&space()}リスクと方針（トラブル・信用・税）
----
***&underdot(#00552e,3px){2) 新事業内容}
&bold(){BJローンは「街の中間デビット決済」になる}
&font(15px,b){【背景】}
&font(20px,#fcc800){▪&space()}街では、請求書払い・電子送金に 10%の手数料（税のようなもの） が乗る
&font(20px,#fcc800){▪&space()}市民も店も「10%が痛い」
&font(20px,#fcc800){▪&space()}そこでBJローンが、10%がかからない（または少ない）支払いルートを用意して需要を取る
&font(15px,b){【仕組み】}
&font(20px,#fcc800){▪&space()}BJローンが「口座（残高）」を管理する（帳簿管理）
&font(20px,#fcc800){▪&space()}例えば提携した店で、BJの方法で払うと2万円の買い物が“2万円のまま”で済む（本来の+10%分を節約できる）
&font(15px,b){【まずは無料（0%）で普及させる】}
&font(20px,#fcc800){▪&space()}最初は信用と利用者を増やすために入金・送金・引き出し等の手数料を0%で開始
&font(20px,#fcc800){▪&space()}いつでもやめられて、預けた金は満額引き出せる設計にする　→ “まず安心して使わせる”フェーズ
&font(15px,b){【いずれ手数料を取る】}
&font(20px,#fcc800){▪&space()}最終的にはどこかで手数料（例：現金化の時に数%･決済時に数%など）を取るが、消費税10%を超えることはない
&font(20px,#fcc800){▪&space()}ただし「いつから手数料を取るか」を最初に固定すると、直前に全額引き出しが起きる → 手数料導入のタイミングは会社側で告知する前提
----
***&underdot(#00552e,3px){3) 街との関係}
&font(20px,#fcc800){▪&space()}市長へのプレゼンは済んでいて、事業の大枠はOK
&font(20px,#fcc800){▪&space()}市の意図としては「10%が減っても、別の形で税収は取りたい」
&font(20px,#fcc800){&space(3)▪&space()}飲食店がテナント料/法人税を払っているのと同じように
&font(20px,#fcc800){&space(3)▪&space()}BJローンも事業が回れば 法人税として納める方針
&font(20px,#fcc800){▪&space()}起業支援として、飲食店と同様に最大3000万円の無利子貸付（資本金的な支援）を受けられる可能性がある
&space(3)→ 当面の運転資金・税支払いの原資にもできる
----
***&underdot(#00552e,3px){4) 運用方法}
&font(15px,b){最初は「完全に人力」で回す前提}
&font(20px,#fcc800){▪&space()}自動システムではなく、まずは人力で回す（エラー上等）
&font(20px,#fcc800){▪&space()}店ごとに連絡/記録の場所（例：六法の専用板）を作り
&font(20px,#fcc800){&space(3)▪&space()}「誰のカードでいくら支払い」だけを投稿
&font(20px,#fcc800){&space(3)▪&space()}BJ側がそれを見て帳簿に反映
&font(20px,#fcc800){&space(3)▪&space()}仮に消費者側帳簿が決済によってマイナスになった場合、加盟店側にはプラスで記帳しつつ消費者へマイナスになった旨を伝える
&font(20px,#fcc800){▪&space()}そのため即時性は落ちる → そこは最初から「遅いの上等」で説明する
&font(15px,b){仕事が“これだけ”にならないようにする}
&font(20px,#fcc800){▪&space()}会社として目指すのは「張り付いて常時対応」じゃない
&font(20px,#fcc800){▪&space()}気づいた人が、気づいたタイミングで対応するスタイル
&font(20px,#fcc800){▪&space()}反映が遅くて会社の評判が落ちる可能性もあるが、まずは運用を成立させて改善する
&font(20px,#fcc800){▪&space()}提携店舗が2～3店舗であれば人力前提で行い、容量を超えた場合は社員の増員または別の方法を考える（bot導入など）
----
***&underdot(#00552e,3px){5) 社内方針・スタイル}
&bold(){① 会社の理念：合わない人は抜けてOK}
&font(20px,#fcc800){▪&space()}この新規事業は「やりたい人がやる」
&font(20px,#fcc800){▪&space()}微妙なら別部門に行く/会社を離れるのもOK（元々の理念）
&bold(){② 部門分けは賛成。ただし“情報は全員が共有”}
&font(20px,#fcc800){▪&space()}仕事が一人に集中するのは良くない（電話窓口が一極化している問題がある）
&font(20px,#fcc800){▪&space()}部門責任者は立てる。ただし「その部門しか分からない」はNG → 誰かが寝ていても止まらないように、情報は全員に共有
&bold(){③ 売り文句は「便利」じゃなく「損しない」}
&font(20px,#fcc800){▪&space()}即時性も利便性も、現行の電子送金より落ちる
&font(20px,#fcc800){▪&space()}でも 10%が浮く＝損を減らす
&font(20px,#fcc800){▪&space()}店側にもメリットがある → 10%分が浮けば、その分もう1品買える可能性が増える（客単価が上がる）
***&underdot(#00552e,3px){6) リスク整理}
&bold(){① トラブルは増える（裁判も増える）}
&font(20px,#fcc800){▪&space()}人力・遅延・確認不足があると、揉め事が起きやすい
&font(20px,#fcc800){▪&space()}その時に備えて、社内帳簿と取引記録は整える（提出を求められる可能性があるため）
&bold(){② 残高確認が面倒になる}
&font(20px,#fcc800){▪&space()}スマホで即確認、みたいな便利さは基本ない
&font(20px,#fcc800){▪&space()}残高は「本人から問い合わせ」等で確認する想定 → ここも“面倒さ”込みで設計している
&bold(){③ 店員・社員の工数が重い}
&font(20px,#fcc800){▪&space()}特に「店の給与が個人請求でバラけている」タイプだと店単位ではなく“従業員単位”で管理が必要になり、板が増える
&font(20px,#fcc800){▪&space()}ここが拡大すると本当に回らなくなるので
&font(20px,#fcc800){&space(3)▪&space()}提携先を絞る
&font(20px,#fcc800){&space(3)▪&space()}専任を置く
&font(20px,#fcc800){&space(3)▪&space()}方式変更するなど、状況を見て調整する前提

&bold(){Q.給与形態が歩合制なのですが、給与管理を店舗側で行う必要はありますか。}
&font(20px,#fcc800)A.ありません。店舗側で発生する手間は専用六法で記入することのみで、BJローンがスプレッドシートを用いて自動的に個人口座と会社口座に振り分けます。

&font(20px,#fcc800)A.店舗側からの請求があった場合は従業員口座の確認が可能になります。なお、個人が別口で開設した口座は店舗側からの確認はできません。
----
&bold(){Q.消費税を払わずに済むということですが、脱税にはあたらないのですか。}
&font(20px,#fcc800)A.消費税の代わりにBJローンが法人税を納めます。また、本事業は既に市に認可されておりますので市とのトラブルは発生いたしません。

&bold(){Q.引き出し･預け入れはどのようにすればいいですか。}
&font(20px,#fcc800)A.引き出し･預け入れを行いたい口座のカードをご持参の上、窓口へとお越しください。

&font(20px,#fcc800)A.対応は店舗側に一任します。名義者本人への確認、警察への通報、支払いの拒否等の対応をご自由におまかせします。
----
&bold(){Q.不正利用が確認された場合、口座の停止はできますか。}
&font(20px,#fcc800)A.ご連絡頂ければ即座に停止可能です。なお、カード本体さえあれば名義と利用者が異なっていても決済が可能となっておりますので、紛失･盗難等には十分ご注意ください。
----
&bold(){Q.体験など、まだ従業員口座を持っていない場合はどのようにすればいいですか。}
&font(20px,#fcc800)A.口座は名義を指定していただければすぐに作成可能ですので、作成をご希望の場合はお申し付けください。

&font(20px,#fcc800)A.決済時手数料は利用者側となりますので、店舗の負担はございません。なお、現在は引き出し手数料のみをかける予定です。

&bold(){Q.不正利用が発生した際、店舗側が責任を負う必要はありますか。}
&font(20px,#fcc800)A.店舗側への過失は問わず、BJローンと不正利用者間でトラブル対応いたします。なお、警察による事情聴取などにご協力いただく場合がございます。

#openclose(show=▶ 住宅ローンスタート直前時点の約款){
&bold(){【白市民向け 住宅ローン貸付契約書兼約款】}

本契約は、貸主（以下「金融側」とする）と借主（以下「借主」とする）との間で締結される住宅ローン貸付契約の条件を定めるものである。借主は以下の内容を十分に確認し、同意の上で契約を締結するものとする。
----
第1条（貸付内容）
1. 金融側は借主に対し、最大5,000万円までの住宅取得資金を貸し付ける。
2. 貸付額、返済回数、返済額は契約時に個別に定めるものとする。
----
第2条（金利）
1. 本ローンの金利は一律10%とする。
2. 借主は、借入元金に対して10%を加算した金額を総返済額として支払うものとする。
----
第3条（返済方法）
1. 返済は週次分割払いとし、返済日は毎週水曜日とする。
2. 分割回数は金融側と借主とで相談して決めるものとする。
3. 借主は定められた返済額を各返済日までに支払う義務を負う。
----
第4条（期限延長手数料）
1. 借主は返済期限までに返済が困難である場合、金融側へ申請することで返済期限の延長を受けることができる。
2. 延長申請は返済日前までに行うものとする。
3. 延長が認められた場合、返済期限は水曜日から土曜日まで延長される。
4. 延長手数料は30万円とし、本手数料は返済額または元金には充当されないものとする。
----
第5条（遅延損害金）
1. 借主が返済期限を過ぎても支払いを行わない場合、遅延損害金が発生する。
2. 遅延損害金は残債務に対して日利0.2%とする。
3. 遅延損害金は遅延が解消されるまで日割りで加算される。
----
第6条（住宅差し押さえ）
1. 借主が返済期限から3日以上経過しても支払いを行わない場合、金融側は当該住宅を差し押さえることができる。
2. 差し押さえ後、借主は当該住宅への立ち入りおよび使用が制限される場合がある。
3. 差し押さえ解除には、未払い返済額、遅延損害金および解除料を支払う必要がある。
4. 差し押さえ解除料は50万円とする。
----
第7条（売却に関する協議）
1. 返済期限から長期間にわたり返済が行われない場合、金融側と借主の協議の上で当該住宅の売却等の対応を検討する場合がある。
2. 売却を行う場合には、ローン残債の整理を目的として売却代金を充当することがある。
3. 具体的な売却方法および条件については、その都度金融側と借主の協議により決定するものとする。
----
第8条（再契約）
1. 金融側が必要と判断した場合、借主との協議によりローン契約の再構築を行うことができる。
----
第9条（ブラックリスト）
1. 重大な滞納または著しい契約不履行が発生した場合、借主は金融側の管理する信用記録に登録され、今後の貸付を制限される場合がある。
----
第10条（契約の同意）
1. 借主は本契約内容を十分に理解し、同意の上で住宅ローン契約を締結するものとする。
}
