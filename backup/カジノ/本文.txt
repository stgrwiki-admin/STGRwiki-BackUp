&font(17px,b,#808080){ダイヤモンドカジノは「全て」のお客様にお楽しみいただけるエンターテイメントを提供致します。}
***&big(){&underdot(#BBBBBB,3px){&icon_fa(fa-solid fa-gem)&space(2)概要　}}
賭けの提供を主軸とした、イベント開催や飲食提供を行っている、複合型エンターテイメント施設。
その他にも、出資や融資などの金融業や施設上階を使ったテナント経営等も行っている。
-2024年4月28日、「[[無馬グループ]]」へ加入。
--街への還元策行う上での負担軽減と、より円滑な業務連携を受けるため参加。
--莫大なカジノ資本を利用した資金援助や、ポスター掲載などの広報を担う。
//
***&big(){&underdot(#BBBBBB,3px){&icon_fa(fa-solid fa-gem)&space(2)ポリシー　}}
店舗内では、&font(){ギャング}・警察・市民関係なく「立場関係なく平等に楽しめる交流の場」となるような経営をめざすと同時に「白市民や街への還元」を軸に掲げ運営している。
-各種ゲームには、白市民でも楽しめるような低レート台と、ギャングが楽しめる高レート台を用意。
-市民でも安心して楽しめるように、店内での&u(){発砲や暴力、脅し、誘拐}などの行為を全面的に禁止しており、違反者には[[オーナー>無馬　かな]]が対応する。
-干渉されずプライベートで楽しみたい方向けに、従業員の許可がないと"絶対に"立ち入れない部屋を貸し出している。
-カジノルールの周知や、町を盛り上げる為、「カジノ王」などの様々なカジノ主催イベントを実施している。
--また、「街を盛り上げる」という想いから、各イベント会社や飲食店が主催する他イベントへの協力・出資に前向きである。
--実際に[[GBC>GoodbyeCircus#Goodbye Company]]に協力を持ちかけたり、[[らびすぴ>らびすぴ#イベント会社「らびすぴ」]]や[[海上レストラン>Urashima]]主催のイベントへの協力をしている。

***&big(){&underdot(#BBBBBB,3px){&icon_fa(fa-solid fa-gem)&space(2)権利　}}
公的に認可された賭博場のため、合法的に賭博が可能である。
-カジノが運営、協力するイベントは「賭博罪」の適用外にすることができる。
カジノ内でのルール違反者に対して出禁の措置を取ることが可能である。
-&b(){ルール：}他のお客様へのご迷惑となる行為。&nbsp(br,15)施設内、施設への発砲行為。&nbsp(br,15)従業員への脅しや暴力行為などの危害を与える行為。

**大型強盗犯罪「カジノヘイスト」対応
***&big(){&underdot(#BBBBBB,3px){&icon_fa(fa-solid fa-circle-info)&space(2)概要　}}
&font(11,gray){犯罪概要については、[[ロスサントスの犯罪について]]頁の「[[カジノヘイスト>ロスサントスの犯罪について#カジノヘイスト]]」項参照}
-当犯罪にて盗難される金庫は国庫のものであるため、本カジノ金庫とは無関係である。
-「街を盛り上げる」というポリシーのため、ヘイスト中のギャングと警察による銃撃については容認している。
//
***&big(){&underdot(#BBBBBB,3px){&icon_fa(fa-solid fa-circle-info)&space(2)対応　}}
-経験則的に停電後は"カジノヘイストが行われる可能性がある"ため、カジノ従業員による避難誘導が行われる。
--避難誘導時は、犯行グループを下手に刺激して命を危険にさらすことのないよう、警察への通報は行わない。
-警察による収束判断の連絡によって通常営業が再開する。
-オーナーの申告により、カジノ襲撃を行ったグループには営業妨害罪も課される。
-避難誘導がスムーズに行われるよう、防災訓練等を予定している。
//
