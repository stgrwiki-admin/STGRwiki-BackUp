*&font(25,#89c3eb){基}本情報
***&underdot(#99CCFF,3px){&icon_fa(fa-solid fa-circle-info)&nbsp(2)概要　}
[[飯田けんつ>飯田　けんつ]]が率いる、元民間傭兵会社[[ACADEMY]]発の[[ギャング]]。

&nbsp(3)▪&nbsp()成長をテーマに掲げ、各々の個性が活きる組織になることを志す。
***&underdot(#99CCFF,3px){&icon_fa(fa-solid fa-gear)&nbsp(2)理念　}
&nbsp(3)▪&nbsp()個性の違う歯車がかみ合い、全員で最高速（トップギア）での成長を目指す。
&nbsp(3)▪&nbsp()基本的に人を詰めたりはしないが、有事の際には徹底的に潰す。
&nbsp(3)▪&nbsp()大型ばかりにはならず、みんなで遊ぶ時間を作れるホワイト企業のような場所にする。
&nbsp(3)▪&nbsp()黒側の夢が叶う場所にする。
&nbsp(3)▪&nbsp()泥臭くみんなで成長していく。
&nbsp(3)▪&nbsp()みんなで辛いことを共有する。(話したくないことは話さなくていい)
&nbsp(3)▪&nbsp()街の全ての人にリスペクトを持って行動をする。
&nbsp(3)▪&nbsp()それに伴い警察に対しても、捕まったとしても会話を大切にし、投げやりにならない。

***&underdot(#99CCFF,3px){&icon_fa(fa-solid fa-gear)&nbsp(2)由来　}
自動車において最高速度が出せるギアを指す用語（トップギア）が由来。
またTOPGEARのモチーフであり理念にも通ずる「歯車」をドイツ語に訳すと「Gang（ギャング）」となり、ダブルミーニングである。&br()
-一人一人の経歴がバラバラであったり、特定の分野に突出した能力を持つメンバー&openclose2(show=※){&nbsp(br,2)（車の運転技術に優れた[[ボス>飯田　けんつ]]、ヘリの操縦技術と知識に優れた[[KT>フランク・ジェスター]]、銃撃戦に優れた[[タマーチ>タマーチ　ニキタ]]、など）&br()}で構成されているため、&br()歯車のようにそのデコボコを補い合う形で全員のギアをかみ合わせたら、トップギア(最高速)を目指せるはずだと考えたことから。&br()

設立初期は「TOPGEAR トップギア」という名称を不必要に公にしない方針だったため、
その名が周知されるまで、警察には「くず鉄ギャング」と呼ばれたり、[[某他組織>NO LIMIT]]には「放課後クラブ」と呼ばれたりしていた。（現在進行系でそう呼ぶ者も居る）
また、その語感から「トッポギ」と呼ばれることも少なくないが、“その人の呼びたいように呼べばいい” のスタンスで何と呼ばれようが否定も肯定もしていない。※「トッポギ」の呼びはじめは恐らく[[某ギャングボス>Mon　D]]。
現在は主に「トップギア」「TG」「トッポギ」と呼ばれることが多い。&openclose2(show=※){&nbsp(br,2)（今後もしフロント企業を作るなら、そう呼ばれる皮肉も込めて「TOPOGIYA トッポギ屋」を作ろうか？と画策しているメンバーも居る様子？）&br()}

***&underdot(#99CCFF,3px){&icon_fa(fa-solid fa-circle-info)&nbsp(2)経緯　}
[[飯田けんつ>飯田　けんつ]]が[[ギャング]]設立に至った理由は以下の3つ
-｢理不尽にはそれ以上の理不尽を｣という考えを可能にする立場がギャングボスであったこと。
-｢夢を叶える街｣を体現できていない人&openclose2(show=※){&nbsp(br,2)（夢半ばでギャングを解散した過去がある人、事情により半グレ期間が長かった人、既存ギャングの門を叩いたけど手が届かなかった人）&br()}が多いと感じ、自身がギャングを設立することで各々のなりたいギャングの理想像を目指せる場を提供したいと考えたこと。
-勧誘できる半グレの人数が多く、[[ACADEMY]]の親組織である[[ARCANA]]と利害関係を結ぶには、これ以上ない好機であると考えたこと。

***&underdot(#99CCFF,3px){&icon_fa(fa fa-user-plus)&nbsp(2)加入方法}
当初の想定では全会一致としていたが、メンバーの起床率の問題もあり今のままでは一生増えないとの意見が多数出たため、
新メンバーの候補となる者はまずは体験期間（1週間～2週間）を設けて、その人柄と組織に合う合わないを判断する。&openclose2(show=※){&nbsp(br,2)（現在のメンバーはみつーを除いてボスの独断で集めたメンバーであるため、今のメンバーを集めたボスなら人を見る目はあるだろうとして現在の体制となった。）&br()}

▼ 体験の雇用について ▼
・[[ボス>飯田　けんつ]]が人柄を見て認めた人であれば、身辺調査及び適性を見た上で体験雇用の判断は[[ボス>飯田　けんつ]]に一任。
・メンバーからの推薦があった場合、&s(){一度[[ボス>飯田　けんつ]]と面談し上記の条件をクリアすれば体験可能。}&br()より間口を広げて出会いの場を増やすため、アンダーボスの&openclose2(show=3人){（[[KT>フランク・ジェスター]]、&s(){[[タマーチ>タマーチ　ニキタ]]}&br()、[[シュガピ>シュガー　ピーチ]]）}にも体験を雇用する権利を持たせることに。

体験メンバーにはメイン拠点としているホテルの一室を与え、スタッシュやガレージを提供している。
&small(){※体験の窓口は広く持つ代わりに、体験中に何か問題が生じれば体験期間の満了を待たずとも即解雇可能とする。}

***&underdot(#99CCFF,3px){&icon_fa(fa-solid fa-circle-info)&nbsp(2)当面の活動方針　}
-大型犯罪では18回連続で利確するなど成功率がかなり高まって来たため、次のフェーズとして捕まった仲間を1人でも多く救うために動く方針にシフト。&br()利確で満足せず、救える救えないの線引を身を持って学ぶため、多少無茶だったとしてもトライしてみて経験値を得ようと考えている。
-大型犯罪後のフィードバックを濃くするため、収束後拠点に集まり各々の動きを精査、何が良くて何が悪かったのかをより明確にする。&br()今までは大型犯罪の連続だったが、成長段階である現状そうした時間も大切だと考えた。
-メンバー各々で配置決めや意見出しを積極的に行い、[[戦闘大臣>タマーチ　ニキタ]]の負担を減らす。&br()今までは[[戦闘大臣>タマーチ　ニキタ]]が総じて指揮していたが、彼の負担を感じ取った[[ボス>飯田　けんつ]]と2人で話した結果その方針に定まった。
-新メンバーの勧誘に関して、勧誘対象は己の意思で黒落ちした者、かつ志望先が無い者を対象とする。&br()白市民を勧誘して黒落ちさせることは望んでおらず、むしろ白の楽しさを謳歌してほしいとも考えている。（[[ボス>飯田　けんつ]]が白市民の楽しさを知っているため）

***&underdot(#99CCFF,3px){&icon_fa(fa-solid fa-car-burst)&nbsp(2)TOPGEARの終焉　}
-ボスが本当にやりたかったことをやろうとアクセル全開にして[[ALLIN]]にぶつかった結果、2025年1月18日をもって解散した。
