*&color(#e0e0e0){&font(#dcd3b2){&icon_fa(fa-regular fa-comments)} ロスサントスでの生き方 }
****&underdot(#dcd3b2,3px){&font(15){黒への興味&nbsp()}}
&image(万十忍-listmaker.png,width=15,height=15,inline)街に来たばかりの頃は黒市民としての道も視野に入れていた。
&image(万十忍-listmaker.png,width=15,height=15,inline)2024年8月、実際にギャングメンバーに相談し白か黒か進路について決断をした。
#openclose(show= ＞入国前の考え){&image(万十忍-listmaker.png,width=15,height=15,inline)世界各国で幾度となくパトカーとチェイスをし、何台も撒いてきた。この街でも警察とチェイスすることで自分の腕を試したいと考えていた。
}
#openclose(show= ＞黒市民との接触){&image(万十忍-listmaker.png,width=15,height=15,inline)銃を持って犯罪をするというよりも、逃がし屋として運転技術を活かしたいと考えた。
&image(万十忍-listmaker.png,width=15,height=15,inline)[[四皇シャンクズ>四皇 シャンクズ]]に紹介された[[ジョーカー>半沢　直ふぃ]]に相談したところ、彼がボスの[[新興ギャング>Trickster]]加入を打診される。
&image(万十忍-listmaker.png,width=15,height=15,inline)1ヶ月程の時間をかけて意思を固めた。加入について返答をする前にジョーカーに峠でのレースバトルを挑む。結果は万十の勝利。
}
#openclose(show= ＞決意){&image(万十忍-listmaker.png,width=15,height=15,inline)新しい夢ができたため、今はギャング加入を辞退する。
&image(万十忍-listmaker.png,width=15,height=15,inline)夢とは黒市民がレースの上位に君臨するこの街で、自身が白市民として最速のレーサーとなること。
&image(万十忍-listmaker.png,width=15,height=15,inline)現在最速のレーサー[[アドミゲス・ハン]]を倒し、名実ともに最速のレーサーとなった際にはもう一度話がしたい。
}
****&underdot(#dcd3b2,3px){&font(15){白市民として&nbsp()}}
&image(万十忍-listmaker.png,width=15,height=15,inline)メカニックを二店舗掛け持ちしながら高級車ディーラーでも働いている。
&image(万十忍-listmaker.png,width=15,height=15,inline)レーサーとしての夢を達成した後は豆腐屋を開業したいと考えている。

****&underdot(#dcd3b2,3px){&font(15){恋愛について&nbsp()}}
&image(万十忍-listmaker.png,width=15,height=15,inline)2024/11/10にBMCメンバー、[[葛城　司]]で行った葛城体験での出来事で[[うさぎさん>山田　パルコ]]を「明確に素敵な人だなと思った」と2024/12/24の3時以降（本人衛生外）BMCで話している。
&image(万十忍-listmaker.png,width=15,height=15,inline)2025/9/6夏祭りにパルコを誘い二人で行ったことについてヨシャパテに尋ねられた際、「好きなんですかね」と返答。
&image(万十忍-listmaker.png,width=15,height=15,inline)尋ねられたら親しい人には隠さず自分の気持ちを話している。
****&underdot(#dcd3b2,3px){&font(15){走り屋として&nbsp()}}
&image(万十忍-listmaker.png,width=15,height=15,inline)[[月ノ島ごう>月ノ島　ごう]]主催の白市民レーサー応援プランに加入。正式にプロレーサーとしての活動を始める。
&image(万十忍-listmaker.png,width=15,height=15,inline)頂点に立つために、[[アドミゲス・ハン]]を始めとしたトップレーサーたちにタイマンレースで勝つことを目標に掲げている。
